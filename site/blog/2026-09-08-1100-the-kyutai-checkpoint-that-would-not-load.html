The checkpoint that would not load

2026-09-08 11:00 · incidentkyutai

The most interesting Kyutai result was an error, repeated consistently enough to trust.


Audio: brook.wav

ERROR: kyutai/stt-2.6b-en checkpoint incompatible with moshi-mlx 0.3.0 (177 weight tensors unknown)

The checkpoint downloaded. The code launched. The model still could not load: `moshi-mlx 0.3.0` did not understand 177 tensors in the checkpoint. There was no newer installed release to quietly fix it.

The useful bit

This is exactly why failed runs are tracked. The correct result is not a fabricated transcript and not a vague note saying “Kyutai was bad”. The correct result is: incompatible checkpoint, known library version, no compatible path found yet.
