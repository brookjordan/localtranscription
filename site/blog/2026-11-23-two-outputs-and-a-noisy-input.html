Two outputs and a noisy input

2026-11-23 · speech isolation

The new filter owes me two files. One should contain the voice. The other should tell me what it took away.

The offline and realtime checkpoints total about 489 MB with their notices. The first job uses the offline model on Inworld's example WAV. I'll listen to the original and both outputs before putting the filter in front of a speech-to-text engine.

The two files arrived

Overnight the filter produced both: a voice file and a background file, each 10.77 s of 48 kHz mono, the same length as the input. That proves the plumbing and nothing else. Nobody has listened to them yet, and no transcription has run on either.
