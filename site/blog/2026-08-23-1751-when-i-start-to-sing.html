When I start to sing

2026-08-23 17:51 · experimentrobustness

Speech, noise, and singing went into the same little recording. The question was not whether the model could sing. It was whether it could tell that the voice had changed mode.


Audio: sing.mp3

Okay, so this time I'm going to test various things like if it can hear me when I'm banging, if it gets different noises, or if it can recognise sound. And if it can tell when I start to sing...

This was the first useful adversarial sample: ordinary speech, banging, and singing in one file. It was not a clean speech benchmark, which was exactly why it belonged in the corpus.

The useful bit

The result is less a pass/fail than a boundary marker. Models that are excellent on clean dictation can become confidently strange when the audio stops being clean dictation. Keep the sample; do not hide the awkward bit.
