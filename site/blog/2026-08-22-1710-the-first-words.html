The first words

2026-08-22 17:10 · milestonebaseline

The project began with one small question: can a local model turn a deliberately improvised voice note into text without sending the audio anywhere?


Audio: brook.wav

Okay then let me do a quick test and see how this ends up sounding. I'm not quite sure what I'm going to say, so I'll make it up and I'll transcribe it later.

The tiny English Whisper baseline got the important bit right. It was not a benchmark yet. It was a microphone, a twelve-ish-second file, and a transcript that was recognisably mine. That was enough to make the next experiment worth doing.

The useful bit

That became the contract: file in, transcript out, with duration, model, elapsed time, and failure data recorded beside it. No server, no Telegram integration, no production mutation. Just a small laboratory harness.
