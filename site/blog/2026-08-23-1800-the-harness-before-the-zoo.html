The useful part of the early work was not the model choice. It was the result shape: source path, duration, model identifier, runtime version, elapsed time, transcript, and failure information.

The useful bit

That shape made comparisons possible later. It also made failures first-class. A model that crashes, stalls, or produces a recognisable error is more informative than a missing cell in a table.
